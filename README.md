# IELTS Speaking Part 1 Practice

一款面向 IELTS Speaking Part 1 的网页练习工具，使用 Emma 考官语音进行提问。

在线使用：[ielts-speaking-part1.pages.dev/practice](https://ielts-speaking-part1.pages.dev/practice)

## 主要功能

- 中国大陆与加拿大地区题库
- Part 1 模拟考试与连续练习
- 按主题进行专项练习
- 标记薄弱主题并提高抽查频率
- 使用中文准备个人化英文答案素材
- 可选本地录音及录音导出
- 练习记录和答案内容仅保存在用户设备中

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
pnpm install
pnpm run dev
```

构建检查：

```bash
pnpm run build
```
